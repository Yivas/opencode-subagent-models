# Code of conduct

## Expected behavior

Treat contributors and users with respect. Keep technical disagreement focused on the code and documented behavior. Give enough context for others to reproduce a problem, and accept that maintainers may reject work that falls outside the project's scope.

Harassment, threats, discriminatory language, sexualized attention, deliberate exposure of private information, and repeated personal attacks are not accepted in issues, pull requests, reviews, or other project spaces.

## Moderation

Maintainers may edit or remove comments, lock conversations, reject contributions, or restrict participation when conduct disrupts the project or targets another person.

For a routine disagreement, use the relevant issue or pull request and keep the discussion technical. To report conduct that should not be posted publicly, use [GitHub Private Vulnerability Reporting](https://github.com/Yivas/opencode-subagent-models/security/advisories/new) and start the title with `Code of conduct`. Include links or screenshots and avoid repeating sensitive personal information.

Reports will be reviewed in private. The project does not promise a response deadline.

## Scope

This policy applies to the repository and to public spaces where someone represents this project. It does not govern unrelated activity outside the project.
